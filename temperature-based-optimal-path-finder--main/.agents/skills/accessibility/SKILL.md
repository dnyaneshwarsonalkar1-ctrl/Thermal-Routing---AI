# Accessibility Skill
Derived from the A11Y Project and W3C WCAG guidelines.

1. **Semantic HTML**: Use `<main>`, `<nav>`, `<button>`, and `<section>` instead of generic `<div>` tags.
2. **Keyboard Navigation**: Ensure every interactive control is reachable via the `Tab` key and visible with an active `:focus-visible` outline.
3. **ARIA Labels**: For custom map controls or floating icon buttons, add `aria-label` or `aria-labelledby`.
4. **Contrast**: Ensure text has a minimum contrast ratio of 4.5:1 against its background.
