# UI/UX Design Skill
Based on standard design system practices (e.g., Ant Design, Material Design).

1. **Aesthetics & Tokens**: Use consistent CSS variables (tokens) for spacing, colors, and typography.
2. **Visual Hierarchy**: Emphasize important elements using contrast, size, and layout.
3. **Micro-interactions**: Provide clear visual feedback for hover, active, and disabled states.
4. **Isometric / Map UIs**: For tactical dashboards, ensure floating cards have distinct drop-shadows and legible contrast against map tiles.
