# Responsive Design Skill
Inspired by standard fluid layout guidelines (e.g., Bootstrap, Tailwind).

1. **Mobile-First**: Define base styles for small screens, using `min-width` media queries for larger displays.
2. **Fluid Typography**: Use `rem` and `em` instead of `px` to scale nicely with user preferences.
3. **Flexbox & Grid**: Rely on CSS Grid for two-dimensional layouts (e.g., map + sidebar) and Flexbox for one-dimensional alignment (e.g., control panels).
4. **Touch Targets**: Ensure all interactive elements are at least 44x44px for touch interfaces.
